# Connect MySQL Database Using Python

## Objective
To connect a MySQL database with Python and retrieve data for analysis using Pandas.

## Dataset
Student Performance Dataset

**Source:** UCI Machine Learning Repository  
https://archive.ics.uci.edu/dataset/320/student+performance

## Tools Used
- Python
- MySQL
- Google Colab
- mysql-connector-python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
- Created a MySQL database and table.
- Imported student data into MySQL.
- Connected Python to MySQL.
- Retrieved records using SQL queries.
- Loaded SQL results into a Pandas DataFrame.
- Created visualizations to analyze student performance.

## Learning Outcomes
Learned database creation, SQL queries, Python-MySQL connectivity, and retrieving database records for data analysis.
