# Python Environment Setup and Data Analysis

## 📌 Objective
To install and configure Python and explore a public dataset using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## 📊 Dataset
**Student Performance Dataset**

- **Source:** UCI Machine Learning Repository
- **Dataset:** Student Performance in Mathematics
- **Link:** https://archive.ics.uci.edu/dataset/320/student+performance
- **Description:** Contains student demographic, social, and academic information, including study time, attendance-related factors, and grades.

## 🛠️ Tools & Technologies

- Google Colab / Jupyter Notebook

- NumPy
- Matplotlib
- Seaborn

## 🔍 Work Performed
- Configured the Python environment.
- Imported the required Python libraries.
- Loaded and explored the dataset.
- Checked dataset dimensions, data types, and statistical summaries.
- Analyzed student final grades.
- Visualized the relationship between study time and academic performance.
- Created charts using Matplotlib and Seaborn.

## 📈 Key Findings
- Student final grades show variation across the dataset.
- Students with higher study time tend to have better average academic performance.
- Data visualization helps identify patterns and relationships in student performance.
