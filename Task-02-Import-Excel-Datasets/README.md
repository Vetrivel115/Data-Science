# Import Excel Datasets Using Pandas

## Objective
To learn how to import datasets into Python using Pandas and perform basic data exploration.

## Dataset
Student Performance Dataset

Source: UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/320/student+performance

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
- Imported datasets using Pandas.
- Explored Series and DataFrame structures.
- Inspected dataset rows, columns, and dimensions.
- Generated descriptive statistics.
- Created visualizations to understand the dataset.

## Learning Outcomes
Learned how to import datasets, work with DataFrames, inspect data, and perform basic data analysis using Pandas.
