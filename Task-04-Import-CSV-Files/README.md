# Import CSV Files Using Pandas

## Objective
To learn how to import CSV files into Python using Pandas and perform basic data exploration and analysis.

## Dataset
Student Performance Dataset

**Source:** UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/320/student+performance

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
- Imported CSV files using Pandas.
- Explored the dataset using DataFrames.
- Inspected rows, columns, and data types.
- Generated statistical summaries.
- Checked missing values and duplicate records.
- Created visualizations to analyze student performance.

## Learning Outcomes
Learned how to import CSV files, work with Pandas DataFrames, analyze datasets, and visualize data using Python.
